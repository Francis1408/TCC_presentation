Comparação das máscaras

Mean Absolute Error (MAE)

  • Média da diferença entre pixels \(N\) da imagem gerada \(S\) e a imagem de prova \(T\).
  • Média entre os 3 canais de cores \(c\) (red, green, blue) entre 0 a 256.
  • Resultado final normalizado entre [0,1].

    • \(\mathrm{MAE} = \frac{1}{3N} \sum_{i=1}^{N} \sum_{c=1}^{3} \frac{\left| T_{i,c} - S_{i,c} \right|}{256} \)

LPIPS (ZHANG et al., 2018)

  • Avalia o quanto as imagens são perceptualmente similares.
  • As imagens são passadas por uma Rede Neural Convolucional (CNN).
  • Cada camada avalia os mapas das imagens com diferentes métricas.
  • Utilização do AlexNet (KRIZHEVSKY et al., 2012).
  • Avaliado dentro de uma região (bounding-box).
